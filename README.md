# 🚀 FocusXP

FocusXP is a modern gamified productivity dashboard built using React, TypeScript, Vite, and Tailwind CSS. It helps users stay productive by managing tasks, tracking focus sessions, earning XP, and visualizing progress with an interactive dashboard.

## ✨ Features

- 🎯 Task Management
- ⏱️ Pomodoro Focus Timer
- 📊 Weekly & Monthly Analytics
- 🔥 Daily Streak Tracking
- 🏆 Achievement System
- 📅 Mini Calendar
- 📈 Productivity Heatmap
- 🎵 Focus Music Player
- 🌱 Eco Impact Dashboard
- 👤 User Profile
- ⚙️ Settings Panel
- 💾 Local Storage Support
- 🌙 Dark Theme UI

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Zustand
- Lucide React

```bash

```
